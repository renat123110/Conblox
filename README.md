# Conblox Engine & Conblox Studio 🚀

**Conblox** — это полнофункциональный движок и редактор, созданный как клон платформы Roblox и Roblox Studio.

---

## 🌟 Возможности Conblox Studio

### 1. Точный интерфейс Roblox Studio (Dark Theme & Ribbon)
- **Top Ribbon Bar**:
  - Вкладка **Home**: инструменты выделения и трансформации (Select, Move, Scale, Rotate), переключение коллизий, настройка сетки привязки (Stud Snapping: 0.1, 0.5, 1, 2, 4 studs), быстрое создание деталей (Block, Sphere, Cylinder, Wedge), палитра материалов (Plastic, SmoothPlastic, Neon, Wood, Metal, Glass, Grass, Concrete, Ice), палитра классических цветов BrickColor, Group / Ungroup (Ctrl+G / Ctrl+U), Anchor toggle, кнопки Play / Run / Stop.
  - Вкладка **Model**: спавны (SpawnLocation), источники света (PointLight), скрипты (Script).
  - Вкладка **Test**: тестирование симуляции мира с управлением аватаром или чистой физикой.
  - Вкладка **View**: включение/выключение панелей Explorer, Properties, Output, полноэкранный режим.
  - Меню **File**: создание новых плейсов, сохранение (`.cblx`), загрузка, экспорт игры в `.exe`, шаблоны (Classic Baseplate, Obby Starter, Physics Sandbox).

### 2. Древовидная иерархия данных (DataModel / DOM)
- Полная реализация модели объектов Roblox:
  - Корень `game` (`DataModel`).
  - Службы: `Workspace` (с гравитацией и камерой), `Players`, `Lighting`, `ReplicatedStorage`, `ServerScriptService`, `StarterGui`.
  - Классы: `Instance`, `BasePart`, `Part`, `SpawnLocation`, `Model`, `Folder`, `Script`, `PointLight`, `Humanoid`.
  - Сигналы (RBXScriptSignal): `Changed`, `ChildAdded`, `ChildRemoved`, `AncestryChanged`, `Touched`, `TouchEnded`, `Died`.
  - Поиск и обход: `FindFirstChild()`, `FindFirstChildOfClass()`, `GetChildren()`, `GetDescendants()`, `IsA()`, `Clone()`, `Destroy()`.

### 3. 3D Viewport и камера Studio
- Текстура легендарных шипов Roblox (Studs) на деталях и базовой плите.
- **Studio Freelook / Orbit Camera**:
  - Зажатая **Правая кнопка мыши (RMB)** + мышь — свободный обзор.
  - Клавиши **WASD / EQ** во время RMB — полет по сцене со сглаживанием.
  - Колесико мыши — масштабирование/зум.
  - Средняя кнопка мыши — панорамирование.
  - Клавиша **F** — фокус/центрирование на выбранном объекте.
- Интерактивные манипуляторы (Transform Gizmos):
  - **Move**: стрелки по осям X, Y, Z с шагом в стады (studs).
  - **Rotate**: кольца вращения с шагом 15°, 45°, 90°.
  - **Scale**: масштабирование деталей по осям.
- Выделение: аутентичная неоновая циановая обводка вокруг активной детали.

### 4. Режим игры и физика (Play / Run / Stop)
- Физический движок rigid-body: гравитация, расчет массы по объему деталей, падение, отскоки, коллизии.
- При нажатии **Play**:
  - Сохраняется снимок мира.
  - На точке `SpawnLocation` появляется классический блочный персонаж Roblox (R6 Avatar: торс, голова со смайликом, руки и ноги).
  - Камера переключается в режим от 3-го лица с орбитальным вращением.
  - Управление: **WASD** / стрелки — бег, **Space** — прыжок. Анимация покачивания конечностей при беге.
  - Реагирование на урон (`Humanoid.TakeDamage`) и возрождение при падении в бездну.
- При нажатии **Run**: симуляция физики и скриптов без спавна персонажа.
- При нажатии **Stop**: мир мгновенно возвращается к состоянию до запуска!

### 5. Редактор скриптов и командная строка (Output)
- Встроенный редактор кода с подсветкой синтаксиса Lua и JavaScript, номерами строк и вкладками.
- Обработка событий коллизий деталей (`part.Touched.Connect(...)`).
- Интерактивная командная строка в панели Output: выполнение команд на лету (например, `workspace.Baseplate.Color = Color3.fromRGB(255, 0, 0)`).

## 🚀 Быстрый запуск

Дважды кликните по файлу:
```
C:\Users\Renat\Desktop\Conblox\run_studio.bat
```
Либо в терминале:
```powershell
cd C:\Users\Renat\Desktop\Conblox
python server.py
```
Conblox Studio автоматически запустится в отдельном окне приложения.

### Экспорт игры и мультиплеер

В Windows откройте **File > Export Game (.exe)**. Для сборки требуется PyInstaller; установите его командой `python -m pip install -r requirements-build.txt`. Экспорт запускает плейс сразу в Play и включает его в автономный `.exe` (для запуска нужен установленный браузер).

Для Ubuntu-сервера используйте [инструкцию установки](deploy/README.md). Во время Play в панели Multiplayer укажите HTTPS-адрес сервера и общий код комнаты. Сейчас между клиентами синхронизируются присутствие и позиции игроков; физика и скрипты остаются локальными.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| **1** | Режим Select (Выбор) |
| **2** | Режим Move (Перемещение) |
| **3** | Режим Scale (Масштабирование) |
| **4** | Режим Rotate (Вращение) |
| **F** | Фокус камеры на выделенном объекте |
| **Ctrl + S** | Сохранить плейс (`.cblx`) |
| **Ctrl + Z** | Отменить действие (Undo) |
| **Ctrl + Y** | Повторить действие (Redo) |
| **Ctrl + D** | Дублировать объект |
| **Ctrl + G** | Сгруппировать в Model |
| **Ctrl + U** | Разгруппировать Model |
| **Del** | Удалить выделенный объект |
| **F5** | Быстрый запуск / Остановка симуляции (Play/Stop) |
| **RMB + WASD** | Полет камеры Studio |
| **Space** | Прыжок персонажа (в режиме Play) |
