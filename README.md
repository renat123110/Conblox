# Conblox Studio

Conblox — локальный 3D-редактор сцен и игровой прототип на JavaScript с интерфейсом, вдохновлённым Roblox Studio. Проект включает редактор плейсов `.cblx`, просмотр сцены, симуляцию физики и персонажа, а также экспериментальную синхронизацию игроков.

## Возможности

- 3D-сцена на Three.js: создание и редактирование деталей, моделей и объектов, настройка свойств, материалов и освещения.
- Панели Explorer, Properties и Output, встроенный редактор скриптов и строка команд.
- DataModel с основными игровыми объектами и сервисами, сигналами и методами для работы с иерархией.
- Режимы **Play** (с персонажем), **Run** (симуляция без персонажа) и **Stop** (восстановление сцены после теста).
- Физика столкновений и гравитации, блочный персонаж, камера от третьего лица и базовое управление.
- Сохранение и загрузка плейсов в формате JSON `.cblx`; доступны стартовые шаблоны.
- Импорт бинарных моделей Roblox `.rbxm` в текущий плейс через меню **File > Import Model** или перетаскиванием файла в окно Studio.

Скриптовый API — собственная частичная реализация, а не совместимый с Roblox движок. Lua-код преобразуется в JavaScript для поддержки распространённых конструкций, поэтому произвольные Lua-скрипты и Roblox API могут не работать. Панель Output показывает логи и предоставляет командную строку.

## Требования

- Python 3 для локального сервера. Для обычной работы Studio внешние Python-пакеты не нужны.
- Современный браузер на Chromium, например Chrome или Edge.
- Windows для запуска через `run_studio.vbs` и экспорта игры в `.exe`.

## Запуск

В Windows запустите `run_studio.vbs`: он поднимет локальный сервер в фоне и откроет Studio в окне приложения или браузере.

Или из корневой папки проекта запустите сервер вручную:

```powershell
python server.py
```

На Windows сервер откроет Studio автоматически. Если этого не произошло, откройте [http://127.0.0.1:28888](http://127.0.0.1:28888). На других системах запустите сервер этой командой и перейдите по тому же адресу в браузере. Не открывайте `app/index.html` напрямую через `file://`: браузер блокирует загрузку модулей.

## Работа с плейсами

По умолчанию Studio загружает `places/baseplate.cblx`. Команда **File > Save** или `Ctrl+S` сохраняет плейс в папку `places/` через локальный сервер; если сервер недоступен, браузер скачает файл. Открыть существующий `.cblx` или JSON можно через меню **File**. Плейсы — JSON-файлы, их можно хранить в системе контроля версий.

## Управление

| Клавиши | Действие |
|---|---|
| `1` / `2` / `3` / `4` | Select / Move / Scale / Rotate |
| `F` | Сфокусировать камеру на выбранном объекте |
| `Ctrl+S` | Сохранить плейс |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить действие |
| `Ctrl+D` | Дублировать объект |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить объекты |
| `Ctrl+G` / `Ctrl+U` | Сгруппировать / разгруппировать |
| `Delete` | Удалить выбранные объекты |
| `F5` | Запустить выбранный режим или остановить симуляцию |
| `F9` | Показать или скрыть счётчик FPS |
| `Alt+S` | Открыть настройки Studio |
| Правая кнопка мыши + мышь | Осмотреть сцену; `WASD` и `E`/`Q` перемещают камеру |
| Колесо мыши / средняя кнопка | Приблизить или отдалить / перемещать камеру |
| `WASD` или стрелки, `Space` | Движение персонажа и прыжок в Play |

## Экспорт игры для Windows

Экспортируйте текущий плейс через **File > Export Game (.exe)**. Для сборки установите зависимость и запустите Studio в Windows:

```powershell
python -m pip install -r requirements-build.txt
```

Экспортированный `.exe` содержит плейс и runtime, запускает игру в режиме Play и использует установленный браузер. Также можно собрать файл из командной строки:

```powershell
python build_game.py places\baseplate.cblx
```

Результат по умолчанию появится в `builds/`. Сборка `.exe` поддерживается только в Windows.

## Мультиплеер и ограничения

Во время Play откройте панель **Multiplayer** и укажите URL сервера, код комнаты и имя игрока. Клиенты обмениваются присутствием и позициями через HTTP-запросы; для публичного сервера используйте HTTPS.

Синхронизация экспериментальная: сервер не управляет игровым миром, а физика, скрипты и изменения сцены выполняются локально на каждом клиенте. Код комнаты не является паролем. Не используйте эту функцию для соревновательной игры или доверенной проверки действий игроков. Инструкция по установке сервера на Ubuntu находится в [deploy/README.md](deploy/README.md).

```text
app/                  Клиент Studio: интерфейс, движок и сторонние библиотеки
places/               Примеры плейсов в формате .cblx
server.py             Локальный HTTP-сервер и API для Studio
server.pyw            Запуск сервера без консольного окна в Windows
run_studio.vbs        Фоновый Windows-лаунчер
build_game.py         Сборка Windows-игры из плейса
deploy/               Файлы и инструкция для Ubuntu-сервера
requirements-build.txt Зависимости только для сборки .exe
```
